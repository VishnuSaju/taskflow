
TaskFlow

A simple desktop task manager built using Python, Tkinter and Pandas.
TaskFlow was created as a small learning project to practise Python programming concepts through a practical application.

Features

Add tasks with start dates and deadlines.
View all saved tasks.
 Automatically calculate urgency based on deadlines.
Mark tasks as completed.
Delete tasks.
Store task data persistently using CSV files.
Validate user inputs and dates.

Technologies Used

Python
Tkinter – GUI
Pandas – Data management
CSV – Data storage
Datetime – Date handling
